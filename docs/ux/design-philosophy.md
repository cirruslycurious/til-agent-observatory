# 1. Design Philosophy

## 1.1 Core Principles

**1. Transparency First**
- Show decisions, not hidden reasoning
- Structured decision events over chat transcripts
- Progressive disclosure (Simple → Deep)

**2. Instrumentation, Not Output**
- The dashboard is the product
- Abstracts are the probe workload
- Metrics > prose

**3. Trust Through Traceability**
- Every action has evidence
- Every artifact is inspectable
- Every outcome is attributable

**4. Minimal Friction**
- No auth
- No onboarding flows
- Generate immediately

**5. Performance Is Signal**
- Latency is visible
- Cost is visible
- Degradation is explicit
