# 0. Product Intent (Non-Negotiable)

TIL is **not** a writing assistant.

It is an **instrumentation harness for agentic AI behavior**, using abstract generation as the observable workload.

> **Output is a vehicle.  
> The data is the product.**

Every UI decision must prioritize:
- observability
- traceability
- semantic clarity
- analytical rigor

This is a **developer instrument**, not a consumer app.
