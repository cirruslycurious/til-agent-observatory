# 9. Mobile Experience (Explicitly Defined)

## 9.1 Product Stance on Mobile

Mobile is **observational**, not analytical.

> Mobile users may **monitor**, **inspect summaries**, and **review outcomes**.  
> Deep analysis is intentionally constrained.

No attempt is made to create parity with desktop.

---

## 9.2 Mobile Capabilities (Allowed)

✅ Generate abstracts  
✅ View Simple workflow timeline  
✅ View final Results + record verdict  
✅ View **Executive Overview** dashboard section  

---

## 9.3 Mobile Restrictions (Intentional)

❌ No Deep Workflow Inspector  
❌ No raw event logs  
❌ No dense tables  
❌ No Sankey / heatmaps  
❌ No density toggle  

---

## 9.4 Mobile UI Rules

- Single column only
- Default density = Comfortable
- Tabs become segmented control
- Timeline stages collapsed by default
- Artifacts summary only (count + type)
- Dashboard = Executive Overview only
- Banner shown:

Desktop recommended for full instrumentation

This preserves authority instead of faking capability.
