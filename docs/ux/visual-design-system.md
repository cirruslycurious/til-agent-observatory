# 2. Visual Design System

## 2.1 Aesthetic

**Style:** Instrument panel / flight deck  
**Theme:** Dark-first, high contrast  
**Mood:** Professional, aggressive, opinionated, confident  

No:
- playful motion
- friendly SaaS copy
- rounded “cards”
- emojis
- ambiguity

---

## 2.2 Color System (Tokenized + Semantic)

### Base
- Background: `#0B0E11` (obsidian)
- Surface 1: `#141821` (graphite)
- Surface 2: `#1B2030` (elevated)
- Border: `#252C3A`

### Text
- Primary: `#E6E8EB`
- Secondary: `#9AA3B2`
- Muted: `#6B7380`

### Accent (single)
- Accent: `#4FA3FF` (identity, actions, focus)

### Semantic (strict usage)
- Accepted / Success: `#3FA37C`
- Rejected / Failure: `#E05D5D`
- Neutral Info: `#4B5563`
- Guardrail ONLY: `#B9A06A`

**Rules:**
- Green = acceptance only
- Red = rejection/failure only
- Yellow tones = guardrails only
- Accent ≠ success

---

## 2.3 Typography

- UI: **Inter**
- Technical / Data: **JetBrains Mono**
- Labels: UPPERCASE + `tracking-wide`
- Assertive, declarative copy only
