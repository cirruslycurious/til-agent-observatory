# Story 4.3: Global Cost Protection

## Status

Approved

## Story

**As the** system administrator  
**I need** global spending controls  
**So that** total costs don't exceed budget

## Acceptance Criteria

**Provider-Level Spending Caps:**
1. OpenAI API key has spending cap: $100/month (configured in OpenAI dashboard)
2. Anthropic API key has spending cap: $100/month (configured in Anthropic dashboard)
3. AWS Bedrock spending cap: $100/month (configured in AWS Budgets)
4. Provider-level caps are configured in provider dashboards (not managed by application code)
5. Provider-level caps are documented in deployment guide

**Daily Cost Monitoring:**
6. CloudWatch alarm: Daily cost > $20 (sum of all job costs from job_budgets.estimated_cost_usd)
7. Alarm triggers SNS notification to admin email
8. Alarm triggers Lambda function to flip Parameter Store flag: `/conference-abstract/system-enabled = false`
9. System checks flag at job start; if false, return "System temporarily unavailable for maintenance"
10. Auto-resume next day (or manual override via Parameter Store)
11. Daily cost calculated from job_budgets table (sum of estimated_cost_usd for jobs created today)
12. **Cost attribution:** Cost attribution is job-creation-day scoped, not execution-day scoped (long-running jobs started yesterday but incurring cost today are attributed to yesterday's budget)
13. Alarm evaluation period: 1 day (24 hours)
14. Alarm datapoints to alarm: 1 (alarm triggers if 1 datapoint exceeds threshold)

**Global Kill Switch:**
14. Parameter Store flag: `/conference-abstract/system-enabled` (boolean, String type: "true" or "false")
15. Manager Lambda checks flag before starting job (at job creation endpoint)
16. If false: Return graceful message to user: "System temporarily unavailable for maintenance. Please try again later."
17. Dashboard shows system status (enabled/disabled) via API endpoint
18. Can be flipped manually for instant system pause (via AWS Console or CLI)
19. Flag is checked synchronously (no caching, always fresh read from Parameter Store)
20. Flag check happens before any cost-incurring operations (before budget initialization, before LLM calls)

**API Gateway Rate Limiting:**
21. Usage plan: 100 requests/minute per API key (API Gateway supports both per-IP and per-API-key; we use per-API-key for consistent tracking)
22. Burst limit: 200 requests
23. Quota: 10,000 requests per day per API key
24. Throttled requests return HTTP 429 with Retry-After header
25. Rate limiting configured in API Gateway (not in application code)
26. Rate limiting applies to all API endpoints (except health check endpoint)

**Lambda Concurrency Limits:**
27. Manager Lambda: Reserved concurrency = 10
28. Worker Lambda: Reserved concurrency = 20
29. Sub-worker Lambdas: Share remaining account concurrency (no reserved concurrency)
30. Evaluator Lambda: Reserved concurrency = 5
31. Concurrency limits prevent runaway cost escalation (hard limit on parallel executions)
32. Concurrency limits configured in Lambda function configuration (not in application code)

**Cost Alerting:**
33. CloudWatch custom metric: `daily_cost_usd` (sum of all job costs per day)
34. Metric emitted daily (via scheduled Lambda or CloudWatch Events)
35. Alarm on cost spike: `daily_cost_usd` > $15 in 1 hour (early warning, before $20 daily threshold)
36. Alarm triggers SNS notification to admin email
37. Alarm does NOT trigger system disable (only daily $20 threshold does)

## Dev Notes

### Previous Story Insights

From Story 4.1 (Per-Job Budget Tracking):
- Job-scoped cost tracking: `job_budgets.estimated_cost_usd` (running total per job)
- Daily cost calculation: Sum of `estimated_cost_usd` for all jobs created today
- Cost tracking happens after each LLM call and web search

**Key Insight:** Story 4.3 implements global cost protection at multiple layers:
1. **Provider-level caps:** Hard limits at API provider level ($100/month per provider)
2. **Daily cost monitoring:** CloudWatch alarm at $20/day, auto-disables system
3. **Global kill switch:** Manual override via Parameter Store (instant system pause)
4. **API Gateway rate limiting:** Prevents abuse (100 req/min, 10K req/day per IP)
5. **Lambda concurrency limits:** Hard limit on parallel executions (prevents runaway costs)

### Technical Constraints

**Provider-Level Spending Caps:**
- Configured in provider dashboards (not managed by application code)
- Hard limits at API provider level ($100/month per provider)
- Cannot be overridden by application code

**Daily Cost Monitoring:**
- Daily cost calculated from job_budgets table (sum of estimated_cost_usd for jobs created today)
- **Cost attribution:** Cost attribution is job-creation-day scoped, not execution-day scoped (long-running jobs started yesterday but incurring cost today are attributed to yesterday's budget)
- CloudWatch alarm triggers at $20/day threshold
- Alarm triggers system disable (Parameter Store flag flipped to false)
- System disable Lambda is idempotent (checks flag before writing, skips if already false)
- **Optional enhancement:** System disable Lambda logs `system_disabled` decision event (for observability symmetry)
- Cost spike warning at $15/hour (early warning, no system disable)

**Global Kill Switch:**
- Parameter Store flag: `/conference-abstract/system-enabled` (String: "true" or "false")
- Checked synchronously (no caching, always fresh read)
- Checked before any cost-incurring operations (before budget initialization, before LLM calls)
- Can be flipped manually for instant system pause

**API Gateway Rate Limiting:**
- Configured in API Gateway (not in application code)
- 100 requests/minute per API key, burst 200, quota 10K/day per API key (API Gateway supports both per-IP and per-API-key; we use per-API-key for consistent tracking)
- HTTP 429 with Retry-After header on throttle
- Applies to all endpoints except health check

**Lambda Concurrency Limits:**
- Manager: 10, Worker: 20, Evaluator: 5, Sub-workers: share remaining
- Hard limit on parallel executions (prevents runaway costs)
- Configured in Lambda function configuration (not in application code)
