## Quick Reference

### Lambda Layers (Docker Required)

```bash
# Build both layers (Docker MUST be running)
./scripts/bundle-lambda-layers.sh

# Verify sizes after build:
# Layer 1 (python-dependencies): 36-38 MB
# Layer 2 (shared-packages): ~640 KB
```

**Why Docker?** Layer 1 contains pydantic with native C extensions that must be compiled for Linux x86_64 (Lambda's architecture). See `docs/ai-context/lambda-layers.md` for troubleshooting.

### Key Commands

```bash
# Deploy to AWS
cd infrastructure/cdk && npx cdk deploy --all --profile YOUR_PROFILE

# Start frontend dev server
cd packages/frontend && npm run dev
```

### Project Structure

```
packages/
├── agents/           # Python Lambda functions
│   ├── manager/      # Orchestration, scoring
│   ├── worker/       # Tool execution
│   └── evaluator/    # Blind assessment
├── api/              # TypeScript API handlers
├── frontend/         # React dashboard
└── shared/           # Shared libraries

infrastructure/cdk/   # AWS CDK stacks
docs/                 # Documentation
scripts/              # Operational utilities
```
